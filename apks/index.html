Bluff

Version 1.1 · 78 MB · Android

The card game of claims and challenges, played together over home wifi. No accounts, no internet needed.

Download Bluff 1.1

Installing

  1. Tap the download button on your phone and open the file once it finishes.
  2. If Android asks, allow your browser to install unknown apps. This is a one-time setting.
  3. Already have Bluff? This installs over it as an update, so you won't need to uninstall first.

Playing

  • Everyone joins the same wifi as the computer running the Bluff server.
  • Enter your name, then start a table or join one from the list.

What's new in 1.1

  • Running out of cards no longer ends the game for everyone. Your last claim can still be challenged, and the rest play on for 2nd, 3rd and so on.
  • The end screen shows the full standings.
