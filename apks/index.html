Taash

Version 1.4 · 78 MB · Android · formerly Bluff

Card games played together over home wifi: Bluff, the game of claims and challenges, and Black Queen. No accounts, no internet needed.

Download Taash 1.4

Installing

  1. Tap the download button on your phone and open the file once it finishes.
  2. If Android asks, allow your browser to install unknown apps. This is a one-time setting.
  3. Already have Bluff? This installs over it as an update, so you won't need to uninstall first. It shows up as Taash afterwards.
  4. On version 1.1? It can no longer join games, so update from here. From 1.2 on, the app offers new versions itself when you connect.

Playing

  • Everyone joins the same wifi as the computer running the Taash server.
  • Enter your name, then start a table or join one from the list. You can also scan the QR code shown on someone's table.

What's new in 1.4

  • The app remembers your name and server, and lists servers you have used before.
  • Scan a QR code straight from the start screen to find the server and join the game.
  • If the host leaves, the next player becomes host, so the rest can keep playing.
  • Black Queen: clearer greyed-out cards, player names under the trick, the last trick stays 10 seconds when pulled back and can be closed, and the next-game buttons sit above the scoresheet.

Since 1.1

  • New game: Black Queen (3–6 players), with a running scoresheet for the same group.
  • After a game, everyone can opt in or out of the next one and vote for which game.
  • The end screen reveals the last challenge and everyone's leftover cards.
  • Updates install from inside the app.
